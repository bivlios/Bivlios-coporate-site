# Bivlios corporate site — writing-first edition with original school video

A small, fast, static, responsive one-page website for **Bivlios Ltd.**, the company behind **Books Giant** and **BooksTube**. Optimized for corporate introductions, partnerships and international inquiries.

## Original Books Giant school entrance animation — integrated

The authentic Books Giant school login MP4 is configured to stream from the owner-provided public S3 link:

`https://s3-eu-west-1.amazonaws.com/school.booksgiant.com/video/bg-banner.mp4`

The hero animation loader (`brand-animation.js`) now accepts this exact HTTPS source and plays it muted, looped, inline and autoplaying. The original illustration is retained as a visual fallback while the video loads, if loading fails, or when the visitor prefers reduced motion. The video itself is **not bundled** into the ZIP; it remains hosted on S3 and needs to stay publicly available.

To host locally in the future, save the MP4 under `assets/` and update the source in `animation-config.json` (for example, `assets/bg-banner.mp4`). See `HOW_TO_ADD_ANIMATION_HE.md` for Hebrew guidance.

## Deploy to Vercel

1. Place these files at the root of a new GitHub repository; do not move the `assets` folder.
2. In Vercel select **Add New → Project**, import the repository.
3. Set Framework Preset to **Other** (static site). Do not set a build command; the site is plain HTML/CSS/JS. Ensure the output directory is `.` or default.
4. Deploy to the autogenerated Vercel URL and preview it on desktop and mobile.
5. Only after approval, connect `bivlios.com` through Vercel **Domains**, then update DNS at your current registrar per the instructions Vercel displays. The existing live website is not changed by creating this project.

Locally, use `python -m http.server 8000` from this folder and open `http://localhost:8000`.

## Updating copy or colors

- Color tokens are at the top of `styles.css` (start with `--purple`, `--royal`, `--yellow`, `--pink`).
- Content translations live in `script.js` in the `copy.en` and `copy.he` objects. The English fallback content is also present in `index.html` for SEO and no-JavaScript accessibility.
- Product cards, illustrations and footer text can be edited directly in `index.html`.
